# escapethejail
point-and-click game like henry stickman.

Here is a link to the actual google slides: https://docs.google.com/presentation/d/1u1bezIvVFuX9FuCjYZwh4KdN8vUlkVQEbv6HQfCp1Aw/edit?usp=sharing

I use hyperlinks to create choices which lead to either a death or an escape from the jail.
